Section 01

QUBO Formulation

Turning the scheduling problem into xTQx — a matrix a quantum circuit can minimise.

xi ∈ { 0, 1 }
One binary variable per task.
x[i] = 0 → task goes to DRAM
x[i] = 1 → task goes to CXL
8 tasks → 8 variables → 2⁸ = 256 possible assignments.
QUBO encodes the cost of every assignment into one matrix Q.
x[i]=0 → DRAM x[i]=1 → CXL 256 combinations
Task Variables

Every task in CXL pays a latency penalty. Higher sensitivity and larger memory = higher cost.

Penaltyi = si × dL × mi
// only when x[i]=1 (CXL):
Penaltyi = si · dL · mi · xi
// total latency across all tasks:
L = Σᵢ si · dL · mi · xi
dL = 200 ns — latency gap between DRAM and CXL.
High sᵢ → optimizer preferentially puts task in DRAM (x=0).
CXL Latency Cost per Task (sᵢ · 200 · mᵢ)

DRAM holds exactly 50% of total memory. We enforce this as a soft equality constraint on CXL load.

// total S = 3912 MB, DRAM cap D = 1956 MB
K = S − D = 1956 MB ← target CXL load
P = λ × ( Σᵢ mi·xi − K )²
CXL load = K → penalty = 0 ✓
DRAM overflow → penalty grows quadratically
Too much CXL → penalty grows quadratically
λ is tuned so the capacity penalty is comparable in scale to the latency term.
Penalty vs CXL Load — λ(Σmᵢxᵢ − K)²

Combine L + P and expand the squared term. The constant λK² is the same for every assignment — it doesn't change which solution is optimal, so it's dropped from the matrix.

// L + P expanded:
Σᵢ ( sidLmi + λ(mi² − 2Kmi) ) xi
+ 2λ Σi<j mimj · xixj
+ λK² ← constant · dropped
Terms in xi alone → diagonal of Q (Q[i][i])
Terms in xixj → off-diagonal of Q (Q[i][j])
xi² = xi for binary variables, so linear and quadratic-in-one-variable collapse together onto the diagonal
Worked Example — Q[0][0]

In xTQx, the coefficient of xi sits on the diagonal, and the coefficient of xixj sits off-diagonal.

// Diagonal — per-task cost:
Q[i][i] = si·dL·mi + λ·(mi² − 2K·mi)
// Off-diagonal — joint CXL penalty (i < j):
Q[i][j] = 2λ · mi · mj
TERMWHERE IN QSIGN
Latency sᵢ·dL·mᵢDiagonalalways > 0
Cap. self λ(mᵢ²−2Kmᵢ)Diagonalcan be < 0
Coupling 2λmᵢmⱼOff-diagonalalways > 0
The capacity self-term λ(mᵢ²−2Kmᵢ) is negative when mᵢ < 2K, meaning the QUBO naturally pulls large, sensitive tasks toward DRAM — exactly the right behaviour.
Q Matrix Structure (upper triangular)
Large positive Q[i][i] — high latency cost if in CXL
Small off-diagonal — coupling penalty (tiny λ here)
How to read the heatmap
■ Dark red diagonal — Q[i][i] dominates because the latency term sᵢ·200·mᵢ is large.
T2 is brightest (1024 MB × 0.8 sensitivity = 163,767).
T4 is second (768 MB × 0.95 = 145,863).

■ Pale yellow off-diagonal — Q[i][j] = 2λmᵢmⱼ. With the small λ used here, coupling terms are 2–16, negligible against the diagonal.

■ Empty lower triangle — QUBO is upper-triangular by convention.

Section 02

RQAOA Algorithm

Recursive QAOA shrinks the n-variable problem one variable at a time until classically solvable, then reconstructs the full solution.

STEP 01
QUBO → Ising Hamiltonian
Map x∈{0,1} to z∈{−1,+1} via  xi = (1−zi)/2

H = Σᵢ hi·zi + Σi<j Jij·zizj

hi = −Q[i][i]/2 − Σj≠iQ[i][j]/4
Jij = Q[i][j] / 4
STEP 02
Build & run QAOA circuit
|ψ(γ,β)⟩ = UB(βp)UC(γp)···UB(β₁)UC(γ₁)|+⟩⊗n

UC(γ) = e−iγH  cost layer — encodes QUBO
UB(β) = Πie−iβXi  mixer — explores states

COBYLA classically optimises γ,β
to minimise ⟨ψ|H|ψ⟩
STEP 03
Measure pairwise correlations
After optimisation, sample the circuit.

For each pair (i,j) compute:
Mij = ⟨ψ|ZiZj⟩  (two-qubit expectation)
Mi  = ⟨ψ|Zi⟩   (single-qubit expectation)

Find (i*, j*) = argmax(i,j) |Mij|
STEP 04
Eliminate one variable
Strongest pair (i*, j*) with |Mi*j*| → 1:

M > 0: zj* = +zi*  → same tier
M < 0: zj* = −zi*  → opposite tiers

Substitute into H  →  H shrinks by 1 variable.
Store substitution for reconstruction.
STEP 05
Recurse until cutoff
Repeat Steps 2–4 on the reduced H.

8 vars → 7 → 6 → 5 → 4 → 3 (cutoff)

At n_cutoff = 3: brute-force 2³ = 8 states.
Pick the lowest-cost assignment.
STEP 06
Reconstruct the full solution
Reverse the substitution chain:

z3 →propagate→ z4 →···→ z8

Convert back: xi = (1 − zi) / 2

Result: x* ∈ {0,1}⁸
x=0 → DRAM    x=1 → CXL
STEP 1 — ISING HAMILTONIAN
The Ising Hamiltonian encodes the same cost as the QUBO matrix, in ±1 spin variables that quantum circuits operate on natively.
